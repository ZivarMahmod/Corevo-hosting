# Dagens genomgångar — designunderlag

Den här mappen innehåller visuella källpaket. Den beskriver inte aktuell kod-,
test- eller driftsstatus.

- `_referens/` — gemensamt referensmaterial.
- `04-installningar-v2/` — inställningsdesign.
- `05-kundportal/` — kundportaldesign.
- `06-frisoradmin-mobil-pwa/` — mobil admin-design.
- `Mobil pwa/` — kompletterande mobilunderlag.
- `klar/` — historiskt sorterade källpaket; namnet är inte ett releasebevis.

Vid implementation gäller det uttryckligen valda paketets filer som visuell
acceptanskanon. Aktuell produktstatus finns endast i `HANDOFF.md`.
